## Consequences for the architecture

1. CPU-only → every avoidable LLM call is expensive (5–15 tok/s). The deterministic /
   NLP / ML / retrieval layers are not an optimisation here, they are what makes the
   system usable.
2. 136 authored posts is a very small corpus → TF-IDF + linear models and MiniLM embeddings are the
   right tools; no fine-tuning, no deep models.
3. Free RAM is the binding constraint → one lazily-loaded singleton LLM, no parallel model
   instances, memory-aware model selection.
